# Webilia Challenge

## Overview

A full-stack coding challenge repository combining a PHP backend with a JavaScript frontend. The repository is kept as a portfolio snapshot of implementation work rather than a claim of production ownership.

## Setup

```bash
composer install
npm install
```

Configure the application using the repository's environment/example configuration, then run the backend and frontend using the scripts defined by the project.

## Scope

The repository represents a challenge/assessment implementation. It should be evaluated from the checked-in source and commit history rather than treated as a deployed production system.

## Portfolio value

This project demonstrates working across backend PHP, frontend JavaScript, dependency management, and full-stack integration in a constrained project setting.

Historical challenge snapshot.
